# 「墨与纸」交互与动效规格

> 本文管交互、手势、动效、触觉和 WebView 工程约束。颜色、字体选择、器材图形、纪录的样子以
> [design-plates.md](design-plates.md)（「杠铃片」）为准，两者冲突时以那篇为准。
> 节号被代码注释引用（`§5.7`、`§12.6`…），改节号要同步改注释。

## 0. 硬约束

1. 健身房单手、可能出汗手滑、光线不定：**抬眼 0.3 秒读到重量和次数。组行数字 ≥ 26px。**
2. 深浅双主题都真实在用；中英双语，中文为主。
3. 单人自用起家，没有社交 / 商业化包袱。

## 2. 色彩

见 design-plates §1。

## 3. 排印与字体工程

**排印铁律**
- 中文永远 `letter-spacing: 0`，永不 uppercase。拉丁小标签（KG / REPS / PR）可以 uppercase + `.08em`。
- 所有数字 `tabular-nums`。数据（重量、次数、体重、统计）走 `data-*` 字号令牌，不用普通输入框字号。
- 字号走 `tailwind.config.js` 的 fontSize 令牌（`data-xl / data-lg / data-md / headline / h2 / body / label / micro`），值在 index.css。
- 正文、数值、可点的控件文字下限 11px；计数、部位 / 器材小标签、分组副字、时间线副行、底栏标签这类辅助小字允许 9–10.5px。

**字体工程**
- 字体全部自托管子集（`scripts/build-fonts.mjs` 扫源码收字），不走 Google Fonts：国内被墙、健身房地下室没信号正是核心场景。
  加了新文案要重跑 `npm run build:fonts`，dev server 不会自动重建子集，漏了会静默掉回系统字。
- 正文字体 `font-display: optional`（中文兜底与目标字度量差太大，晚到的 swap 会让整个列表重排）。
  代价由 `src/utils/fontGuard.ts` 兜：探测 DOM 没用上字体就本会话一次性重载。
  「字形就是全部意义」的字体（标题字体）用 `block` + 预加载，见 design-plates §2。
- 字体栈永远留系统兜底（用户自定义的动作名可能含子集外的字）；预加载的 `<link>` 即使同源也要写 `crossorigin`。

## 4. 圆角 / 阴影 / 层级

- 圆角只用 `--radius-*` 令牌（`rounded-card / control / chip / sheet / stamp`），不写裸 `rounded-xl` 之类。
- 阴影只表达海拔，不兼做选中态。z-index 只用 `tailwind.config.js` 里的语义常量。

## 5. 动效

### 5.1 令牌

时长、缓动、按压缩放全部是 index.css 里的令牌（`--dur-tap / base / exit / page / stamp / reveal`、
`--ease-paper / stamp / ink / leave`、`--press / --press-sm`、`--move`）。组件里不写数字时长、不写 `transition-all`
（它会连带过渡 clip-path / grid-template-rows，和揭示动画打架）、不写 `active:scale-9x`。
`--ease-stamp` 是唯一允许过冲的曲线，只给盖章类时刻。

### 5.2 节奏总纲

**落笔 → 渗墨 → 盖章。** 每条动效必须归到其中一个动词，归不进去的删掉。
- 落笔（clip-path / scaleX 由一端展开）＝内容出现、进度、确认；
- 渗墨（背景色 / 墨色的一次涨落）＝瞬时反馈、状态变化；
- 盖章（scale + rotate 带过冲）＝只给纪录落定和长按达成。

### 5.3 逐场景规格

| 场景 | 做法 |
|---|---|
| 写下一组 | 新行 clip-path 自上而下揭示，同时把占位高度撑开（否则下方按钮先跳）。只有刚添加的行播，动画完摘掉入场类（§11 坑 1） |
| 底稿 / 抄来的值 | 淡墨 + 虚线＝「这是抄的，等你确认」，确认后转实墨（§12.6） |
| 落笔聚焦 | 输入框底部 2px 强调色下划线从中心向两端展开。聚焦是描边不是光晕：不用 `ring` / 外发光 |
| 墨色过冲 | 替代 scale 弹跳：落位时墨色瞬间加深、220ms 内回到目标浓度，位置零位移。用于「因你的操作而改变、需要你注意到」 |
| 长按进度 | 底边 1.5px 线向右画出（不用圆环）。**前 120ms 什么都不出**，否则每次点按都闪；同时浮出标签说明会发生什么（§6.4） |
| 弹层开关 | 手势 1:1 跟手；松手用速度投影判定 `d.y > H×0.28 ‖ v > 0.6`，收尾时长 `clamp((H−y)/max(v,.8), 120, 260)`；pointerdown 从进行中动画的当前位置接管 |
| 结束训练（刊末页） | 逐行 clip 揭示（stagger 60ms）+ 总容量 count-up，**必须可点击跳过**；破纪录时升级为落章序列，同样可跳过 |
| Tab 切换 | **不做横向滑动**（Tab 之间没有空间方向关系）。先出后进、零重叠：旧的淡出上移 4px，新的淡入上移 6px |
| 列表 stagger | `delay = min(i,6) × 32ms`，封顶第 7 项（否则快速滚动时内容追着你长）。clip 揭示，不是飞入 |
| Toast | clip 从左往右印出；底边一条剩余时间线 `scaleX 1→0`，时长＝停留时长。撤销条尤其需要它 |

### 5.4 数字动画规则

**数字只在「因为用户刚做的这个动作而改变」时才动；页面加载时就在的数字一律不动。**
动：底栏「N 动作 · M 组」、弹层「本次已加 N」、刊末页总容量 / 总组数、纪录 `prev → next`。
不动：输入框里的值、只读历史值、时间线统计、计时器（逐秒硬切）、Recharts（`isAnimationActive={false}`）。
count-up 必须有超时兜底：rAF 可能一帧都不跑（§11 坑 3），否则读数永远停在起始值。

### 5.5 状态变化用墨的深浅表达

不用尺寸或光晕的变化表达状态的变化：不用 scale 弹跳（`anim-chip-pop` 已废）、不用 box-shadow 光晕脉冲（`anim-ring` 已废，
Material 的辐射语汇，且逐帧重绘）。点行即添加的非模态确认用 `anim-ink-mark`（一次渗墨 + 常驻边杠）。
值退回底稿时要「淡下去」，不瞬切。

### 5.6 reduced-motion

**reduced-motion ≠ 无动画，而是无位移 / 无缩放 / 无旋转**；颜色与不透明度过渡保留。
所有位移写成 `calc(12px * var(--move))`，reduced-motion 下 `--move: 0`。
「我的」里有应用内三态开关（跟随系统 / 开 / 关）：安卓开发者选项里「动画时长缩放 = 关闭」也会触发系统的 reduced-motion，
很多人为了「手机更快」关了它，会静默关掉所有动效。
**例外**：长按进度线和 Toast 剩余时间线在 reduced-motion 下仍然要画，它们是功能性指示，不是装饰。

### 5.7 触觉

只设计两档：一下「点击感」、一下「确认感」，**靠时长区分，不靠振幅**——中低端机没有振幅控制，轻 / 中 / 重手感一样。
用 `navigator.vibrate`（不走 bridge，延迟比插件低），常量在 `src/utils/haptics.ts` 的 `H`。
1. 先发震动再启动画（马达机械启动天然落后 10–30ms）。 2. 脉冲锚在语义时刻（状态提交那一帧），不锚在动画起点或 `transitionend`。
3. 绝不在 rAF / 滚动回调里调；全局去抖 55ms。 4. 必须在用户手势的同一个任务里调，否则被静默丢弃。
5. 有全局开关：安静的健身房里自己嗡嗡响的 App 很讨人嫌。

## 6. 关键组件

### 6.1 组行＝账本行

- 行不是填充盒：无背景无边框，只有自己的 `border-bottom`。不在容器上另画稿纸横纹——行高不一（递减档、「再加一档」）时横纹必与行线错开。
- **数值 26px**，长数字按格宽收字号（只有装不下的才让步，下限见 §3）。单位内嵌在数值右下角，没有表头副行。
- 父行与递减子行共用一份网格列变量（`--cols`，列宽在 `src/utils/exerciseConfig.ts`），根治错位；列用 `minmax(0,1fr)`，否则数字撑破整行。
- 组号是 48×48 的可点胶囊（2026-10-26 从 36 放大：它是每组必点的目标，按记录开销计分 36 dp 一次 2.6 比特，48 dp 降到 2.3；行高 52 装得下）；删组热区 44×44。交替组的组号上方叠着动作简称，仍是 30×30。递减子行是引文式缩进（左边线），不是反色块。

### 6.2 动作卡＝一页稿纸

- 刊头行：动作名 + 右侧计数（「已做 / 总组数」），下方分隔线。
- **删除动作只有一处入口**：刊头右侧 ⋯ 菜单。卡片底部只留通栏「＋ 添加组」。
- 眉批标记（练法、底稿出处等）：需要点的才有边框，可点的用伪元素把热区补到 44px。

### 6.3 添加动作弹层

- **点＝添加，弹层不关**：一次渗墨 + 头部「本次已加 N」+ 震动；450ms 内的第二击防误触。
- 长按＝动作面板（管理），不能拖。「整理」常驻头部，是动作库唯一的编辑入口：整理开着时点＝面板、按住即拖（归细分 / 调顺序）。
  示意 `docs/demos/region-board-v3.html`。
- **真正需要点的才配拥有边框，纯只读信息不配**（只读信息用眉批式小字）。选中态不加阴影。

### 6.4 长按

- **高频动作绝不藏进长按。**「添加组」「添加动作」永远是可见按钮；长按只承载低频的次级操作（§12.5 通则 2）。
- **长按必须自我解释**：进度线开始画的同时浮出标签说明会发生什么（「加递减」「拖动排序」…），半路松手那一闪就是教学。
  实现：`useLongPress`（默认 500ms）+ `LongPressAffordance`。

### 6.5 图表与热力图

- 不用渐变面积填充；末点常驻数值标签（出汗手滑时点 tooltip 是最差的读数路径）；数值智能去零（80 而不是 80.00）。
- 颜色一律在运行时用 `getComputedStyle` 读 CSS 令牌，不在 JS 里硬编码调色板（否则不随主题变）。
- 热力图强度按**当日总组数**分档，不按场数：单人一天几乎只有一场，按场数会退化成二值图。

### 6.6 弹窗与危险操作

- 所有弹窗走 `Modal.tsx`（`center / sheet / full`），portal 到 body；底部操作区统一 `<ModalFooter>`。
- `useDismissAnimation` 把「挂载」与「打开」解耦，才有退场。退场只用 opacity，不反向播 clip（像倒带）。
- 不装 `tailwindcss-animate`，不引入动画库（§7.2）。
- **危险操作不靠颜色区分，靠形态与位置**：列表里的删除入口一律是 ⋯ 菜单里的墨色文字项；
  `danger` 实心只出现在确认弹窗里，全 App 唯一允许的是重置账号那类不可撤销的确认。
- 删组、删递减档、删动作：**单击执行**，不弹确认、不靠长按保险；点错了用顶栏的全局撤销（§12.5 通则 3）。删整场训练、清空账户留确认框。

## 7. 工程约束（Capacitor Android WebView）

### 7.1 渲染成本

- 常驻栏（顶栏、底栏、训练页浮栏）不用 `backdrop-blur`，靠不透明背景：它压在滚动列表上，每个滚动帧都要重新模糊。
- 弹窗遮罩可以模糊（背景静止），但**模糊层与淡入层分离**，否则淡入期间每帧重新模糊。
- hover 规则包在 `@media (hover: hover)` 里（触屏上 hover 会粘住）。
- Modal 必须 portal 到 body：动画、transform 都会建层叠上下文，把就地渲染的弹窗关在局部里被导航栏盖住。
- 动 transform 的包装层里不放 `position: fixed` 子元素：transform 元素会成为 fixed 后代的包含块。

### 7.2 技术选型

- 不引入动画库（入口 chunk 已大，Framer Motion 一类无法懒加载）；需要的小工具自己写。WAAPI 不用 `commitStyles`，最终状态由 React state 持有。
- 不用 `mix-blend-mode`（用 `color-mix()`）；不动画 `box-shadow`（伪元素画静态阴影，只动 opacity）；滚动列表里逐项不用 clip-path 动画。

### 7.3 合成器安全 / 危险属性

- ✅ 安全：`transform`（含独立 `translate / rotate / scale`）、`opacity`。
- ⚠️ 能上合成器但有开销：`filter`、`backdrop-filter`。
- ❌ 触发 Layout：`width / height / padding / margin / top… / border-width / font-size / line-height / flex-* / grid-template-* / gap`。
- ❌ 触发 Paint：`background-* / color / border-color / border-radius / box-shadow / clip-path / mask-*`。
- 判定法：动画播放中在 Console 跑 `const t=performance.now(); while(performance.now()-t<1500){}`，仍然流畅＝在合成器上。
- `will-change` 只在动画开始前加、结束后删。

## 9. 纪录判定（`src/utils/prDetect.ts`、`src/utils/prRecords.ts`）

| 规则 | 内容 |
|---|---|
| weight / volume | 历史最大单组重量；单次训练总容量。同时命中 weight 优先（更硬） |
| reps | 只在动作不记重量（自重类）时启用 |
| 历史为空 | 不算纪录（否则第一次训练全是纪录，仪式当场贬值） |
| 编辑旧训练 | 不触发 |
| 阈值 | 提升 < 0.5 kg 或 < 1% 不算（挡住 kg⇄lb 换算的浮点噪声） |
| 数量上限 | 最多 2 枚；更多的合并成「另 N 项刷新」 |
| 底稿行 | 不参与任何判定（§12.6） |

**非纪录日也必须有收尾**：九成训练不破纪录，每次结束训练都有刊末页，破纪录时才升级为落章。

## 10. 已定

- 递减档默认值：上一行显示值 −5 当前单位（换算残留先 floor，下限 0），次数同上一行。
- 文案语气：陈述与肯定，不用命令式（「今天多记住了一点」而不是「训练已保存」）。

## 11. 动画实现的三条规矩

1. **同一元素上两个动画会打架**：入场动画结束后摘掉入场类；反馈类动画的选择器权重要显式压过入场规则。
2. 往滚动容器里插入行时页面会因滚动锚定自己漂移，需要时给容器加 `overflow-anchor: none`。
3. **rAF 与 CSS 过渡在隐藏标签页里不推进**：依赖动画结束的逻辑都要有兜底 timer；调试「动画不动」先查 `document.visibilityState`。

## 12. 操作层

### 12.1 训练部位选择（进页第一步）

点加号进空白训练页，先问「今天练哪里」：六枚部位印（胸 / 肩 / 背 / 腿 / 臂 / 「⋯」其他）三列两行，选了就填好训练名。
英文下印面换成首字母（C S B L A O），形制不变。印的样子见 design-plates §2。
**询问的四个条件缺一不可**：还没有动作 / 不是在编辑旧训练 / 标题为空 / 本次还没选过。
「本次选过」存**训练 id** 不存布尔：换一场自然重新问，中途把动作删光也不会再弹回来。

### 12.2 力竭标记

`SetLog.toFailure`。**仪式感属于「事实的产生」，不属于「界面的操作」**：纪录是系统判定的、配一场落章；
力竭是用户上报的、只配一个记号，可逆（再点一次取消）。做成可见开关而不是隐藏手势：它是数据，该和别的字段一样看得见。

### 12.3 横向拖动改值

重量格（次数格同一套，档位 1 / 2 / 5）整格就是 scrub 区：点一下照旧聚焦输入框，横向拖改值。
每 10px 落一档，档位由速度决定（×1 / 2 / 5 / 10）；步长按**显示单位**走，一格多少由器材和馆档案决定（design-plates §3）。
1. **横向位移 ≥ 12px 才认定是拖动**（不是常见的 6）：出汗手滑的一次点很容易带出 6px，误判的代价是重量改错。
2. `touch-action: pan-y`，不是 `none`：手指落在重量上时列表要能滚。
3. **吞掉拖完补发的那次 click 用时间戳，不用布尔**：手势以 `pointercancel` 结束时没有 click 来清布尔，下一次正常点击会被吃掉。
4. 换算残留（132.28 这类非 0.5 倍数）在拖动的第一档先取整并吃掉这一档；切单位、打字、±5 都不取整。
5. 速度计算里 `dt` 钳到 ≥ 1：高刷屏同一毫秒两次 move 会把「甩得最快」读成 0。

### 12.4 FAB 印谱扇开（快速开练）

点按 FAB 语义不变（进新训练页）；**长按 120ms 后六枚部位印从拇指下扇形摊开**，滑到某枚松手＝开练并选好部位。
示意与调参面板 `docs/demos/fab-seal-fan.html`；几何常量在 `TabNavigation.tsx`。
- 顺序固定为印谱阅读序，不按使用频率排：位置稳定才长得出肌肉记忆。命中判定按离印中心的距离，目标要虚胖。
- 前 120ms 什么都不出；松手总时长 < 250ms 按点按算；≥ 250ms 原地松手＝留在点选模式（点印可选、点空白收回）。
- 「⋯」分支与页内一致：不填名、聚焦标题、弹层不弹。
- 英文补签：英文印面是首字母，扇开时六枚等于六个谜面，所以英文下每枚印径向外侧常驻一张名字签；中文不加。
  签的半径和宽度是两头卡出来的（不压印角、不出屏、相邻不撞），宽度必须恒定，悬停不许变长。
- 实现坑：`pointercancel` 完整复位（清 timer、收扇、清悬停）；stagger 用 setTimeout 加类而不是行内 `transition-delay`
  （会赖在行内样式上拖慢之后的悬停过渡）；点选模式打开的 `pointer-events` 收扇时必须还原，否则隐形的印挡住页面点击。

### 12.5 操作层通则

1. **手势是加速器，不是唯一入口。** 每个手势都有可见的点按路径做后备，并自带一次自教学（短按闪标签 / 页内小技巧）。
2. **一个手势词全站只有一个意思。** 长按＝次级操作（递减档、管理面板、拖动排序、时间线菜单）；横向拖＝改值或翻页；点按永远是主动作。
3. **破坏性操作先执行，靠全局撤销兜底，不弹确认框**：手势的错误率天然高于点按，弹窗挡不住手滑、只挡得住流畅。
   2026-10-25 起没有各处的撤销条了：顶栏一对全局撤销 / 重做（services/undoJournal.ts），在存储层记每一步写入，
   墓碑也进日志、跟着一起撤。撤销 / 重做不弹「已撤销」提示，底部提示只留报错这类没做成的。例外（仍弹确认）：删整场训练、放弃训练、清空账户；导入 / 恢复备份另有自己的确认和回滚。
   结束训练不在例外里（2026-10-26 起，之前每场都弹「确认结束？」）：训练页的按钮同一键再点一次才结束（4 秒内），顶栏误触有一次机会又不用重新瞄准；结束后能从时间线接回 / 编辑。首页「进行中 → 结束」离上下文远，仍问一句。
4. 每个手势都过一遍三件套：`pointercancel` 完整复位；动画收尾回调幂等（transitionend 与兜底 timer 只许进一个）；
   拖完的 click 用时间戳吞掉，且吞一次就作废。

### 12.6 底稿与组的两种状态

- 每组只有两种状态：**待做**（`SetLog.ghost`，虚线组号）/ **做完**（实心组号）。底稿、新长出的行、从计划开练的行，一律从待做开始。
- 添加练过的动作时，上次同动作的每一组以待做行铺进来，眉批写出处（「底稿 · 上次 X月X日」；别的馆时加一句刻度可能不同）。
  不继承力竭、递减档；继承动作的器械配置。
- **点组号才算做完**（点「竭」也算）；改值只改值，改过的格子记 `SetLog.touched` 变实墨。全零的组点不实。
- 改一组的值，后面待做且该格没手动改过的组跟着变：重量保持差值，次数只跟原值相同的。规则在 `src/utils/workbench.ts`。
- **红线：底稿永远不会静默变成数据。** 结束训练时待做行整行丢弃，只剩底稿的动作连动作一起丢；有改过数没点完成的组，确认框要说出来。
- 读取路径必须把待做行当不存在：刊头组数与容量、底栏「N 组」、时间线、纪录、热力图——草稿会带着待做行自动持久化，漏一处就是假数据。
- 进度不发明新机制，只把已有状态念出来：刊头「已做 / 总组数」、做完时组号落印、休息标记（§12.13）。
- 「复制为今天的训练」和计划开练都走同一套底稿语义。

### 12.7 动作卡拖动排序

长按刊头行 500ms（全站长按语言：120ms 静默 + 进度线 + 「拖动排序」标签）→ 卡片浮起 → 兄弟卡实时让位 → 靠近视口上下缘自动滚页 → 松手落位。
实现在 `useCardReorder.ts` / `ReorderStrip.tsx`，两张卡以上才挂。
- 热区保持 `touch-action: pan-y`：长按满之前手指移动 > 10px 就取消、把滚动还给浏览器；抬起之后才用非被动 touchmove 拦滚动。
- 刊头里的 ⋯ 按钮不参与拖动。刊头行的长按从此归拖动排序，别的次级入口另找位置。

### 12.8 时间线长按菜单

时间线的训练卡：**点按＝展开详情，长按＝操作菜单**（编辑 / 补记动作 / 并入上一场 / 复制为今天的训练 / 删除）。
低频操作不在卡面常驻按钮，卡面只剩内容。菜单与动作卡的 ⋯ 菜单同一形态（卡内浮出 + 点外关闭），不另造浮层。
删除整场先确认（通则 3 的例外）；长按达成后松手带出的 click 必须吞掉，否则会顺手展开卡片。

### 12.9 翻月横滑

计划页月历的日期区左右拖，1:1 跟手翻月——全 App 唯一真正有左右空间关系的界面（所以 §5.3 不许 Tab 横滑，这里可以）。‹ › 按钮保留，走同一段落定动画。
- 松手判定复用 §5.3 的速度投影：`|dx| > W×0.28 ‖ |v| > 0.6 px/ms`，收尾 `clamp(剩余距离/max(|v|,.8), 120, 260)`。
- 接管条件：横向 ≥ 12px 且横 > 竖（§12.3）；dt 钳到 ≥ 1。
- 落定回调必须幂等：transitionend 和兜底 timer 双触发会一次翻过两个月。

### 12.10 已否决

- 滑动划掉一组：保留点击。手势化的收益来自隐喻贴合度，不是省一次点击。
- 组间休息计时器：做过，不好用，已删。不要再提。

### 12.11 场地

`WorkoutSession.gym` 存字面量馆名，候选从历史训练现算（`src/utils/gyms.ts`），**不落 prefs**：新增同步 key 要改四处、漏一处静默丢，
为能从既有数据派生的东西不值。会话上的新可选字段随整对象同步，免迁移。
- 默认沿用上一场：连着去同一个馆永远不用碰那个控件。开练不问馆（2026-10-26 起；之前每次开练都弹「这场在哪个馆练」，与这条相悖），只有一场都没标过时才弹——新用户在那里建第一个馆。历史不回填、不按日期推断——没标就是不知道。
- 场地本身只做标注；哪些器材的纪录只在同馆比、重量怎么按馆取整，见 design-plates §3「馆档案」。
- 图表上换馆不加记号，tooltip 里写馆名。底稿眉批带出处馆名；`prefillGym` 无条件记来源馆，「是不是同一个馆」渲染时再判
  （加完动作再改本场场地是常见操作）。

### 12.12 时间线密度

一场一行三列：日期柱 / 标题 + 副行 / 右对齐计数。天粒度且当天只有一场时组头吃掉，日期由卡片左列承担；
其他粒度或一天两场时保留组头。副行是「时间 · 前三个动作」（回看时想知道练了啥，不是练了几个）。
场地 chip 必须可压缩并自己截断：标题才是主信息。

### 12.13 休息标记 / 做到哪了

全场只有一个指针，落在**缝**上（两组之间），不在行上：组间休息时问的是「我在哪两组中间」。示意 `docs/demos/set-pointer-alternating.html`。
- **指针不存状态，由组的状态推出**：最后一条做完的行之后（`workbench.pointerSeam`）。重开工作台、删组之后它自己落在对的地方；不进 `SetLog`、不落盘。
- 作用域全场唯一：同一时刻只可能在一个地方休息，交替组 / 超级组就是在两个动作之间来回。
- 递减档之间不算缝（递减组的定义就是不休息）；一组的缝取整块（母行 + 递减档 + 「再加一档」）的下边缘。
- 点组号＝选中这一组；点的是指针下面的待做组，指针前进到它正下方（经过的有数待做组记做完）。点做完的组只选中，指针不往回跳，什么都不退回（2026-10-25）。往回挪只能拖书签：往下记做完，往上退回待做，值都保留。
- 改值的跟随：改的若不是这个动作里最新做完的那组（后面还有做完的组），后面的组一律不跟；同一组里的递减链照样保持差值。
- 选中的那一组整块之后露出 −5 / +5 两颗宽键（当前单位，下限 0，不取整）。
- `RestBookmark` 静止时零测量：它是组区正常流里的零高节点，CSS 自己贴在缝上；只在拖动开始那一帧扫一次全场缝位。
