# 真机手测清单

装到手机上（`npm run android` 或 live reload）之后扫一遍，**整张几分钟内过完**。每项只看一眼、凭手感判断。

脚本管看不见的东西：`npm run check` 测规则（取整、合并、墓碑、备份、导入、文案表），`npm run e2e` 走关键路径、盯存进去的数。
这张清单只管脚本判断不了的：**手感、观感、动画在不在走、整屏有没有漏翻**。Playwright 的鼠标不是安卓 WebView 里的手指，
拖得「对」不等于拖得「顺」。改版频繁的新界面先在这里看，稳定了再考虑写进脚本。

## 手势手感

- [ ] **长按时间线卡片**：按住约半秒出菜单，进度线和说明标签跟着画，松手不会顺手点进第一项。
- [ ] **长按组号**：进度线画满加一档递减，没按满就松手只闪提示、不加。
- [ ] **随手点组号**：拇指带着一点滑动、点在框边上，连点十几组每一下都选中、指针跟到它下面，往回点也跟；从组号上起手翻页不会误点。练完看首选项「点按记录」里有没有红的「没触发」。
- [ ] **横拖一格多远**：慢拖重量，量规上的游标走到刻度正好跳一格、震一下，两头的数就是落点；正常手速不会一下跳两格；首选项「快滑加速」关掉后怎么甩都是一格。
- [ ] **配重片加片**：给一种形式设 2.5 的加片后，± 和拖动在 20 / 22.5 / 25 之间走，大图顶板上多一枚小片、说明写「插销 20 + 加片 2.5」；换一个插销器械的动作，药丸排里直接有这种形式。设过加片的形式，大图下面单独一行「−1.5 ｜ 加片 1 / 2 块 ｜ +1.5」，两头的键拇指好按、不碰到刻度轨和组行；点一下这一组少挂 / 多挂一块（插销不动），图和说明跟着变。药丸排相邻两枚不容易点串。
- [ ] **馆档案单位确认**：编辑馆点「存好」先到确认页，杠铃片和五类器材的单位逐行列出、可当场改，和片子单位不一样的行标黄、可一键改齐，「没问题，存好」才真的存；馆列表里单位不齐的馆标着「N 档是 kg」。表单和确认页上存的配重片形式 / 哑铃等的「台」点一下展开，单位、最轻一格、每格、加片当场改、立刻生效。
- [ ] **横划数字**（组行的重量 / 次数、配重片「最轻一格 / 每格」）：慢划一档一档走、甩一下跳几档，档位角标跟手，松手不弹键盘。
- [ ] **配重片刻度轨**：轨上竖拖跟手、每片一声咔哒 + 短振，拖到最轻一格挡住；在图上和两侧正常翻页不会改到重量。
- [ ] **触屏点进组格**：点进去即全选，这一下触摸不会把选区收掉。
- [ ] **「添加动作」分类页**：竖栏跟着列表滚动亮当前组、点竖栏跳得准；长按行出动作面板（不添加、松手不误点面板按钮）；「兼练」点开收起顺手。
- [ ] **编辑部位**（整理 → 竖栏底部）：长按一行抬起拖排序跟手、松手落定；点名字就地改名；删细分后动作回未细分、顶栏撤销拿得回来；新建同名的系统细分是把它恢复回来。
- [ ] **底栏「＋」按住**：部位印谱扇开，滑到某个印上松手直接开练；轻点照常进新建页。
- [ ] **弹层下拉关闭**（动作详情 / 特别关注 / 选馆 / 首选项）：拉过 110px 松手顺势划出、遮罩淡出，不先跳回原位；不到就回弹；内容滚到一半往下拉是往回滚。轻拉回弹后再点 × / 遮罩，退场动画照常。
  CSV 导入、馆档案表单没有抓手条、拉不动；馆档案改过东西时点遮罩 / 返回 / × 停在表单上提示没存。
- [ ] **改回上次**：改一组的重量，别的组不动；卡片左下角出现「↺ 改回上次」，点一下指针下面改过的组都回到上次的数，顶栏 ↶ 一下撤回。
- [ ] **做完的组不怕误划**：全做完又没选中的卡，在重量格、大图、刻度轨上划只滚页面、不改值；点组号选中后又能拖。设了最重一格的台拖到底、± 到底都停住且不再震。
- [ ] **操作条与键盘**：打字时操作条收起；用系统返回键或键盘收起键收掉键盘后它回来，转屏后不误判。
- [ ] **交替卡**：标题的动作名按满约半秒能拖着排序，松手不弹成员面板；短按照常开面板；点简称不误触 30px 的组号。
- [ ] **安卓返回键一次只关一层**：卡片 ⋯ 菜单、交替卡成员 / 改记面板、选卡面板、添加动作弹层里的器材 / 动作 / 改部位面板、时间线长按菜单、印谱点选态。
- [ ] **单手点成对按钮**（体重历史行、目标卡、计划卡、「上次 x」改回）不误触旁边那颗；时间线展开详情点动作名，点在上一个动作最后一组下沿时不误进下一个。
- [ ] **选动作搜索框 ✕**：键盘收起后点 ✕ 不弹键盘；键盘开着时点 ✕ 清掉词、键盘留着接着打。

## 观感

- [ ] **深色 / 浅色 / 跟随系统**各切一次：文字、分割线、卡片底色都看得清，没有白底白字或残留的浅色块。浅色下各配一次玫红 / 紫，看一眼选中的 PB 组号；
  系统浅色时把外观切成深色再点强调色，仍是深色，「我的」页围度图跟着变色。
- [ ] **英文界面**：首选项切到 English，首页 / 计划 / 我的 / 新建训练各扫一眼，界面文字里没有汉字（训练标题、动作名是用户数据，不算）。
- [ ] **得意黑**在 20px 动作名上的观感。
- [ ] **动作设置**：点大图上方的小药丸打开，「在 X」一段里插销 / 挂片、最轻一格 / 每格、器械自重都在，自重填了值才多一行「只做参考 | 算进记录」，切到算进记录后组行的数要加上自重，点「完成」收回，药丸文字跟着变。
- [ ] **同馆几台器械**：大图上方一排药丸，点另一台立刻切、没做完的组跟着吸到新刻度；台子多了能横滚，不会带着页面左右晃。设置里点「最轻一格」那行再点预设，填的是最轻一格；横划只在 1 · 2.5 · 5 · 10 · 15 · 20 里跳。
  没存过台时末尾那枚另一种单位的候选（「10 + 10 lb」）会不会太吵；「最重一格」行清空显示「—」，摞子底下那道线的位置；馆档案里「最轻一格」行和上面一档对齐、空着时占位显示一档。
- [ ] **器械单位整卡**：kg 馆、kg 显示，选一台 10 + 5 lb 的龙门架，组行、插销、底栏键整卡写 lb（110 / +5 lb）；切顶栏单位这张卡不变，同场杠铃卡跟着变。
  交替卡两个成员都存过台时，卡头下那行在 390 宽下的换行；成员面板里药丸排在「上次」行下面。
- [ ] **训练页顶栏**（360 / 375 宽）：训练中那一行今天只有日历图标，馆名正常截断、不被挤没，日期热区不和返回键、馆按钮抢点；补录到昨天后写「11/12 周三」也不折行。带正负动作的操作条 6 颗键不挤。
- [ ] **点本场已有的动作**：弹层里点打开前就有的 ×1 行（普通卡、交替卡里的成员各一次）→ 弹层关、滚到那张卡并闪一下；这次刚加的再点仍是取消；计划编辑器里照常加。
- [ ] **恢复 / 重置**：练到一半去覆盖恢复或重置，确认框多一句会清掉进行中的训练、排版自然；重置后首选项出现「撤销上次恢复、导入或重置」，点了数据回来。用 JSON 文件覆盖、撤销之后重载都有提示，备份页「上次备份」随之刷新成刚才。
- [ ] **撤销时进行中那场留着**：练到一半（记 1 组）→ 导入一份 CSV → 回训练页再记 2 组 → 首选项点撤销，确认框多一句「进行中的这场会保留」→ 重载后训练页还是这场、3 组都在。合并恢复后的提示是「已合并：新增 N 场训练」，本机删过的有几场没带回也写着。
- [ ] **添加动作弹层**：375 宽连加两个，头部「添加动作 ✓ 2 …」不换行、不截断；器材做法行铺开后各页不太挤；母行小灰字「上次 宽握 60 kg×10 · 5 天前」读着顺、不被截断；母行和做法行的 ×N 分开计数看着能接受。
  切英文、系统字号调到最大再开一次：× 还在屏内，挤不下时先压「Bring partners」再截标题。搜一个被器材筛掉的名字，末尾那行「另有 N 个被器材筛选挡住 · 清除筛选」读着顺。
- [ ] **⋯ → 历史**：360 宽下菜单不出屏、不压下面的卡；详情关掉后训练页滚动位置不变。
- [ ] **「我的」页自动备份行**：时间 · 路径一行放得下、截断好看；未开启 / 权限失效时红字加按钮不挤。
- [ ] **提示条与开练键**：提示条出现时不压住 FAB。顶栏后台推送失败那枚静止的灰色同步图标和同步中的转圈一眼分得清。
- [ ] **居中弹窗在矮屏 / 大字体下**（日期选择器等）：内容区能滚，「确定」一直可见，里面的拖动数字仍拖得动。
- [ ] **动作设置第一层**：名称输入框、类型 / 部位 / 细分属性表和下面「记录哪些数」之间的间距和分隔线；做法管理里「拆成独立动作」按钮在属性表下面。

## 动画在走

- [ ] **全局撤销 / 重做**：训练中改数、点组号、加组、删动作，顶栏 ↶ 一下撤一步、↷ 一下回一步；结束训练后在首页 ↶，回到训练页、做完的组都在；删一场训练（先确认）后 ↶ 拿回来。
- [ ] **结束训练的刊末页**：总容量数字滚上去，破纪录时印章落下、手机震一下，页面停着等点一下才收。没破纪录时约 1.9 秒自己收，「比上次」几行在这之前读得完，总容量降级后版面平衡。
- [ ] **动作弹层**：「添加动作」从底部滑上来，「完成」收下去，不闪不跳。开场一次加几个再关，停在第一张新卡上；中途只加一个停在那张。
- [ ] **时间线**滚到底续加载时不跳。

## 锁屏回来全灰时怎么取证

练一半锁屏、回来界面全灰（有时十来秒自己恢复，有时要清后台）。两种假设：A）某层弹窗遮罩残留，返回键能关掉；B）WebView 没在画（渲染进程被杀 / 冻结 / 卡死）。
证据只在清后台之前存在，所以顺序不能反：

1. **先别清后台，也别杀 App。** 看一眼此刻的时间，之后对 logcat 用。
2. **按一下安卓返回键**，记下结果：立刻恢复 → 偏向 A；没反应或要等很久 → 偏向 B。只按一下，再按会退出页面。
3. **插线，在仓库根目录依次跑两个脚本。** 第一个不依赖 WebView 调试，正式包也能跑；第二个是 CDP 探针，只对 debug / 测试包有效，正式包会直接告诉你连不上。

```powershell
.\scripts\phone-gray-diag.ps1
```

```powershell
node scripts\phone-webview-probe.mjs
```

把 `test-artifacts\gray-<时间戳>.log`、`gray-<时间戳>-probe.json` 和两个脚本的终端输出一起发到对话里，附上第 2 步的结果。

原生壳里有看门狗（`MainActivity`，logcat tag `FitlogWebView`，`phone-gray-diag.ps1` 会把它算作高价值行）：每次解锁回来记一行 `frame after resume: NNms`；6 秒没出帧记 `no frame 6000ms after resume` → `terminate render process` → `render process gone`，随后页面重载、进行中的训练接回。
读法：灰屏时日志里有 `frame after resume` 且毫秒数正常 → 网页照常在画，问题在窗口 / 合成那一层，看门狗管不到；有 `no frame` 但没恢复 → 看 `rescued within` / `no render process handle` 那几行（60 秒内只救一次，API 29 以下拿不到渲染进程）。
