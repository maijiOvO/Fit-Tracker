# 真机手测清单

装到手机上（`npm run android` 或 live reload）之后扫一遍，**整张几分钟内过完**。每项只看一眼、凭手感判断。

脚本管看不见的东西：`npm run check` 测规则（取整、合并、墓碑、备份、导入、文案表），`npm run e2e` 走关键路径、盯存进去的数。
这张清单只管脚本判断不了的：**手感、观感、动画在不在走、整屏有没有漏翻**。Playwright 的鼠标不是安卓 WebView 里的手指，
拖得「对」不等于拖得「顺」。改版频繁的新界面先在这里看，稳定了再考虑写进脚本。

## 手势手感

- [ ] **长按时间线卡片**：按住约半秒出菜单，进度线和说明标签跟着画，松手不会顺手点进第一项。
- [ ] **长按组号**：进度线画满加一档递减，没按满就松手只闪提示、不加。
- [ ] **横划数字**（组行的重量 / 次数、配重片「最轻一格 / 每格」）：慢划一档一档走、甩一下跳几档，档位角标跟手，松手不弹键盘。
- [ ] **配重片刻度轨**：轨上竖拖跟手、每片一声咔哒 + 短振，拖到最轻一格挡住；在图上和两侧正常翻页不会改到重量。
- [ ] **触屏点进组格**：点进去即全选，这一下触摸不会把选区收掉。
- [ ] **「添加动作」细分格**：长按小卡出动作面板（不添加、松手不误点面板按钮）；「整理」里按住即起、拖小卡排顺序，浮卡跟手，松手落定不跳，撤销条撤得回。
- [ ] **整理里的细分 / 部位**：表头改名、左右移、删掉（动作回到未细分，提示里说几个；顶栏撤销能拿回来）；新建同名的系统细分是把它恢复回来。
- [ ] **底栏「＋」按住**：部位印谱扇开，滑到某个印上松手直接开练；轻点照常进新建页。

## 观感

- [ ] **深色 / 浅色 / 跟随系统**各切一次：文字、分割线、卡片底色都看得清，没有白底白字或残留的浅色块。
- [ ] **英文界面**：首选项切到 English，首页 / 计划 / 我的 / 新建训练各扫一眼，界面文字里没有汉字（训练标题、动作名是用户数据，不算）。
- [ ] **得意黑**在 20px 动作名上的观感。
- [ ] **动作设置**：点大图上方的小药丸打开，「在 X」一段里插销 / 挂片、最轻一格 / 每格、空载都在，点「完成」收回，药丸文字跟着变。
- [ ] **弹层压在弹层上**：计划编辑器里点「从动作库选」，动作弹层盖在编辑器上面；保存键在 4 个动作时仍在屏内。

## 动画在走

- [ ] **全局撤销 / 重做**：训练中改数、点组号、加组、删动作，顶栏 ↶ 一下撤一步、↷ 一下回一步；结束训练后在首页 ↶，回到训练页、做完的组都在；删一场训练（先确认）后 ↶ 拿回来。
- [ ] **结束训练的刊末页**：总容量数字滚上去，破纪录时印章落下、手机震一下，不点也会自己收。
- [ ] **动作弹层**：「添加动作」从底部滑上来，「完成」收下去，不闪不跳。
