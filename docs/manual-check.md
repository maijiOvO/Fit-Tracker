# 真机手测清单

装到手机上（`npm run android` 或 live reload）之后扫一遍，**整张一分钟内过完**。每项只看一眼、凭手感判断。

脚本（`npm run e2e`）管看不见的东西：存进去的数、墓碑、单位、推送失败、时区、英文漏翻、修过的 bug。
这张清单只管脚本判断不了的：**手感、观感、动画在不在走**。Playwright 的鼠标不是安卓 WebView 里的手指，
拖得「对」不等于拖得「顺」。

改版频繁的新界面先在这里看，稳定了再考虑写进脚本。

## 手势手感

- [ ] **长按时间线卡片**：按住约半秒出菜单，进度线和说明标签跟着画，松手不会顺手点进第一项。
- [ ] **长按组号**：进度线画满加一档递减，没按满就松手只闪提示、不加。
- [ ] **横划数字**（组行的重量 / 次数、配重片「最轻一格 / 每格」）：慢划一档一档走、甩一下跳几档，档位角标跟手，松手不弹键盘。
- [ ] **配重片大图拖动**：跟手不卡，拖到最轻一格挡住、不会更轻。
- [ ] **细分格「整理」里拖小卡排顺序**：按住即起、浮卡跟手，松手落定的动画不跳。
- [ ] **底栏「＋」按住**：部位印谱扇开，滑到某个印上松手直接开练；轻点照常进新建页。

## 观感

- [ ] **深色 / 浅色 / 跟随系统**各切一次：文字、分割线、卡片底色都看得清，没有白底白字或残留的浅色块（脚本只验了 `.dark` 类名有没有挂上）。
- [ ] **配重片设置面**：点大图上方的小药丸打开，设置面原地换掉大图，点「完成」收回（原来脚本里那两张不做断言的设计稿截图 `stack-closed.png` / `stack-open.png` 看的就是这个）。

## 动画在走

- [ ] **撤销条**：删一场训练，底边的倒计时线在匀速缩短，约 5 秒走完。
- [ ] **结束训练的刊末页**：总容量数字滚上去，破纪录时印章落下、手机震一下，不点也会自己收。
- [ ] **动作弹层**：「添加动作」从底部滑上来，「完成」收下去，不闪不跳。
