design-plates §4 剩下的五项。规范里只有清单、没有画法，这页给每项 2–3 个方向，挑完我再按选中的落地。 壶铃图形规格清楚（单只定重、剪影随重量变大、不上色），已经直接做进训练页的器材大图了，不在这页。 「建议」是我的倾向，理由写在每个方向下面。

镁粉白 = 纪录（规范：纪录不借片子的颜色）。

A · 里程碑横排 + 热力图镁粉点 建议

里程碑按「每边第一次挂上某种整片」算（一片蓝、两片蓝、一片红…），三大项各取最新一枚。热力图格子中间的白点是破纪录那天。

B · 只加热力图镁粉点，不做里程碑

当天破了纪录

改动最小。「按动作」里已经有纪录，里程碑算是第三处展示成就，怕重复就只做点。

5 · 底部「开练」的部位印章扇

长按底部开练按钮弹出的扇形部位印。现在是马善政书法字，是全站唯一还在用这个字体的地方（规范定了阶段二退役）。

A · 现状：书法印

胸肩背腿臂

有个性，但和「杠铃片」这套几何、器物的语言不搭；字体子集还要单独打包。

B · 正文粗体方印 建议

胸肩背腿臂

保留「印」的形状和扇形手势，只把字换成正文字体最粗的一档、黑框。退掉书法字体，少打包一个字体文件。

C · 去掉印，改成文字胶囊

胸肩背腿臂

最朴素、和筛选标签同一种样子。但扇形展开时胶囊不如方印好认，手势的仪式感也没了。
