健身房器材档案

每个馆设一次「有哪些片子、各类器械一档多重」。训练页的 ±按钮、拖动步长、配片都跟着这场训练所在的馆走，不用再在首选项里手动设「加一档」。手机里的馆和数据都是示例：今天在「国内」练，底稿抄自上一次在 F4L（磅片馆）练的那场。

可以这样试

  1. 看卧推：上次在 F4L 练的 140 lb，这里挂不出来，底稿自动取整成最近能挂的 62.5 kg，右边标着 原 140 lb。高位下拉、哑铃同理。
  2. 点「原 140 lb」：切回原值，这时大图下面给两个就近能挂的重量，点一下就改过去。
  3. 在卧推的重量格里直接打 63：照原样记，大图下面同样给出 62.5 / 65 两个选项，不报错。
  4. 点左上角馆名换到 F4L：没动过的底稿跟着换成 F4L 能挂的重量；你打过、点过的不动。
  5. ±按钮每次正好一档，第一下先落到最近能挂的重量上。坐姿腿屈伸的 ⋯ 里可以单独设一档。

就近取整的规则

  • 能挂的重量按这个馆实际有的片子算：杠重 + 两边能凑出来的重量。少了某种片，能挂的重量就跟着变，不是简单按步长取整。
  • 严格取最近，两边一样近才取轻的（2026-10-18 定）。
  • 只自动改「没人碰过」的底稿：抄来的、跟着平移的、切馆时还没动过的。你打过、拖过、点过的一律不动。
  • 取整过的格子标原值，点一下切回。
  • 手打的数照原样记：大图画最接近的配法，下面给上下两个能挂的重量，点了才改。整页不会出现「配不出」。
  • 龙门架 / 器械 / 哑铃同一套规则，取整到这个馆、这台器械的那一档。
