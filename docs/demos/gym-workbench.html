馆档案 × 工作台

把馆档案、就近取整、「单位就是片子」合进现在 App 里加动作、继承、改值的整套逻辑。手机里是今天在「国内」（公斤片）练，历史上一次在 F4L（磅片）。数据都是示例。点「组号」= 这组做完；点做完的再点 = 退回。

可以这样试

  1. ＋ 加动作：加「杠铃平板卧推」。底稿抄自上一次在 F4L 的 135 / 155 / 155 lb（最后一组带递减 135 lb），按国内的公斤片取整成 62.5 / 70 / 70（递减 62.5），每行标「上次 x lb」。
  2. 改第 1 组（拖不了，用 ± 或直接打字）：后面没动过的组跟着平移，再各自吸到能挂的重量；打一个 63 试试，后面的组不会被带成 73。
  3. ＋ 加组：照抄最后一组（含递减档）；＋ 递减：比上一档轻「一档」（这个馆、这件器材的一档），不再固定减 5。
  4. 点卧推名字下面的练法换成「哑铃」：器材变成哑铃，没做的组重新按哑铃的一档取整；做完的组不动。
  5. 加「史密斯卧推」「倒蹬」：挂片式器械，按杆 / 滑台自重 + 片子算，不再当成配重片插销。⋯ 里设这台的自重。
  6. 加「辅助引体」「负重臂屈伸」：带符号。辅助按这个馆器械的一档取整；负重按腰片能凑的重量取整。
  7. 加「平板支撑」：只记时间，没有重量，什么都不取整。
  8. 右上角切 lb / 换馆：所有没做完的组换到新单位重新取整，做完的组不动（标着它当时的片子）。

每条路径怎么处理

现有路径新规则
加动作 · 抄上一次抄来的底稿按今天的馆和单位就近取整（严格取最近，等距取轻），每行标「上次 x」。只抄同一个练法；不抄今天这一场自己（现在会）。
复制整场 / 计划开练同上：落到今天这一场的馆和单位。计划里的目标重量带上单位存，避免 lbs 来回换算漂移。
加组（照抄最后一组）照抄，不取整：抄的是你刚在这个馆、这个单位下定的数。
改值带动后面后面没动过的底稿先平移同样的差值，再各自吸到最近能挂的重量。打的那一组本身照原样。
± 按钮一下＝这个馆这件器材的一档；第一下先落到最近能挂的重量。首选项里的「加一档」只给纯数字的动作兜底。
递减档默认比上一档轻一档（器材的一档），再吸到能挂的重量；不再固定减 5。
换练法练法自己的器材标签可能换了画法（杠铃 → 哑铃）：没做的组按新画法重新取整，做完的不动。
切单位 / 换馆（你手动点的）没做完的组（含改过数的）换到新单位重新取整；做完的组不动，标它当时的片子。
同步 / 切开发环境带来的单位变化不重新取整：只认你手动点的切换。
史密斯 / 倒蹬 / 哈克 / T 杠新画法「挂片式器械」：起始重量（杆 / 滑台）+ 片子；起始重量按「这个馆 × 这个动作」在 ⋯ 里设。
带符号（辅助 / 负重）辅助按这个馆器械的一档取整（看绝对值）；负重按腰片能凑的重量取整。
没有重量指标的动作不画图、不取整。
编辑旧训练只读那场的馆和片子画图；不因为今天的单位 / 馆去改它。
龙门架 / 器械 PB只和同一个馆比（用训练上标的馆）；没标馆的历史单独算一组。
