馆档案 × 工作台

现在 App 的整套工作台交互，加上馆档案、就近取整、「单位就是片子」。今天在「国内」（公斤片），历史上一次在 F4L（磅片）。数据都是示例。黑色横线是指针：落在最后一组做完的后面。

交互（照现有 App）

  • 点组号：待做、在指针下面 → 做完，经过的有数的待做组一并做完（别的卡先整张挪到当前卡下面）；在指针上面 → 原地补做；刚做完的那组 → 退回；更早做完的 → 指针挪回它下面，后面的退回。全零的组只选中。
  • 选中的组（组号实心）下面出 −一档 / +一档 / 递减。默认选中指针下面第一组待做。
  • 长按组号（0.5 秒）：加一档递减。
  • 重量 / 次数格左右拖：每 10px 一档，拖得快一次两档 / 四档；第一下先落到最近能挂的重量。点一下：打字，全选旧值；离开输入框时按总差值带动后面。
  • 顶部大图也能拖（配重片竖拖），改的是这张卡上选中的组（没选中就是下一组待做）。
  • 带动后面：重量按差值平移再各自吸到能挂的重量；次数只带动原值相同的组；递减档按同一档位跟着变。做完的、改过这一格的不跟。
  • 删组：点行尾 −，可撤销。⋯：和下一个动作交替做 / 拆开、这台器械一档多重。
  • 结束：有「改过数但没点完成」的组会提醒，那些组结束时会丢掉。

路径处理
加动作 · 抄上一次只抄同一个动作的上一次（沿用那次的做法），跳过今天这一场；按今天的馆和单位就近取整（严格取最近，等距取轻），行下标「上次 x」。
加组照抄最后一组（含递减档），不取整。
带动后面平移差值后吸到最近能挂的重量；打的那组照原样。
± / 递减一档＝这个馆这件器材的一档；第一下先落到能挂的重量。
拖动（格子 / 大图）每档一档；第一下吸附。
换做法做完 / 改过的不动；没动过的按新做法的上一次重填（器材可能换了）。
切单位 / 换馆没做完的组换到新单位重新取整（没动过的从「上次」原值重算）；做完的不动，标当时的片子。
挂片式器械（史密斯 / 倒蹬…）按杠铃算，只算片子的重量，不算杆 / 滑台。
多种器材的动作拆成同一个动作的不同做法（罗马尼亚硬拉：杠铃 / 哑铃）。
带符号辅助按器械一档；负重按腰片，一档＝最小那片。
交替组行序：做完的按先后，待做的轮换；不画大图。重量规则同上，各自按自己的器材。
合并到上一场时间线菜单里手动点的操作，不会自动发生；不额外处理。
