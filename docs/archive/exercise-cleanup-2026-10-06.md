# 动作库整理清单（2.5，2026-10-06）

依据：生产快照 `fitlog-backups/prod-snapshot-2026-10-06.json`（42 场 / 47 个自建动作）。只读，没改任何生产数据。

这次新加的功能都能直接在 App 里完成下面的整理：

- **并入另一个动作**：添加动作弹层 → 长按动作（或整理态点动作）→「并入另一个动作…」。被并的动作变成目标动作的一个做法，带着原来的细分和器材；历史、纪录跟过去，记录本身一条不改，撤销条可撤回。做法名自动去掉目标名，比如「窄距高位下拉」并进「高位下拉」会变成做法「窄距」。
- **做法带细分 / 器材**：动作面板 →「做法」→ 点做法展开，选它自己的细分和器材。带细分的做法在细分格里单独成一张小卡。
- **热身细分**：每个部位第一列都是「热身」。
- **负荷记法**：动作设置 →「负荷记法」选「辅助 − / 自重 / 负重 +」。

下面分两类：**可以直接做的**，以及**要你拍板的**（看名字我判断不了是不是同一个动作）。

### 器材标签统一

「龙门架」（系统的「健身房」标签被改名而来）和「绳索」在混用。同样是绳索动作，有的标龙门架，有的标绳索：

- 只标龙门架：直臂下压、直杆头顶三头屈伸、宽距对握龙门架坐姿划船、绳索正向三头下拉、绳索二头弯举、龙门架夹胸、头顶绳索三头屈伸、单手绳索侧平举
- 只标绳索：三头直臂下压、单臂下压、绳索下压
- 两个都标：直杆二头弯举、单手三头绳索臂屈伸

建议统一成一个，推荐留「绳索」（系统自带，英文也有），再把「龙门架」器材删掉；也可以反过来。器材筛选目前要两个都点，统一后点一个就行。

### 不用动的

- 「曲肘蝴蝶机」和「悍马卧推」：快照里有两个原名都叫「悍马卧推」的自建动作，其中一个早先改名成了「曲肘蝴蝶机」，另一个「曲肘蝴蝶机」被删掉（隐藏）了。名字解析规则写死了（新建的优先），历史归属是稳定的，不用动。

## 怎么执行

两种都行：

1. **你在 App 里点**：上面每一项都是一两步操作，并入可以撤销。
2. **我来做**：你在上面的表格里圈定（比如「1–14 照做，15–18 不并，器材统一成绳索」），我写一个只改动作库的脚本，先在开发库（生产快照的拷贝）上跑一遍，截图给你看，你确认后再改生产数据。
