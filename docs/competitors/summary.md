# 竞品汇总对比

> 6 款健身记录 app（训记、Lyfta、Hevy、Alpha Progression、Gym WP、健身房训练）和 fitlog 的对照：记录开销、门槛与付费、逐项功能对照。逐款细节见各自报告（[索引](README.md)）。
> 测试日期 2026-10-26。记录开销按 [`effort-standard.md`](effort-standard.md) 计分，单位是「标准组」：1 分 ≈ 想一下 + 点一个 48 dp 的目标。
> fitlog 的数是 2026-10-26 记录开销第一包（组号 48 dp、开练不问馆、结束同键再点一次、首页「再练一次」、换动作自动滚）之后的；改前的数见 [`effort-fitlog.md`](effort-fitlog.md)。

## 结论

1. **fitlog 第一次记一场的开销最低**：64 分，竞品在 91–124 分之间。
   领先的大头在**加动作**：fitlog 点部位印再点动作格，加 5 个动作共 5 分；竞品都要在搜索框里打英文关键词或翻长列表，要 25–37 分。
2. **「记一组」本身没有领先，和竞品持平**：T1 里 20 组合计 fitlog 56 分，竞品 55–76 分（Lyfta 55 分，比 fitlog 低）。
   首组和改重量，fitlog 也要打字或连点 ±，和竞品的自带数字键盘差不多贵。
3. **老用户每天的开销（T3）大家差不多**：22–31 分，fitlog 22 分，最低；健身房训练 23 分第二。
   有预填时，每组都是「想一下 + 点一下」，所有 app 都在 1 分上下。差距只在开场、收尾和完成键的大小：fitlog 开场一下、收尾两下同一键，全程没有弹窗。
4. **「不用精确点击」只体现到了「标准组」那一步**：fitlog 每组点 48 dp 的组号（2026-10-26 前是 36 dp），正好是标准组的 1.00 分，和训记、Lyfta、健身房训练的完成键持平。
   但「不用看」还没有：健身房训练的 `LOG NEXT SET` 是固定在底部的 293×51 dp 大按钮，Gym WP 有 Hands-Free 自动推进；按这套规则要短边 ≥ 192 dp 才算闭着眼点得中，谁都还没做到。
5. **记录以外，差距大的是门槛和打扰**：
   - 不要账号、不锁功能、没广告、导出免费，6 款里**没有一款四条全占**。
   - 最接近的两款各差一点：健身房训练全免费但有插页广告，也不能导出；Alpha 不要登录、免费导出 CSV，但核心卖点都锁在 $99.99/年的订阅里，而且弹窗不断。
6. **功能上**：「按馆的片和器械」整条线、自动备份、全局撤销是 fitlog 独有的。
   竞品普遍有而 fitlog 缺的记录功能是热身组、RPE/RIR、替换动作、休息计时、训练时长；其中休息计时是有意删掉的。详见「功能对照」。

- **首组**：健身房训练最便宜。点完 `LOG NEXT SET` 后，它会自动滚到下一个空组、弹出键盘、把焦点放进重量格，省掉了「找格子、点格子」。
- **改重量**：Lyfta 最便宜。它的自带键盘上直接打新数，「下一步」键顺手就完成这一组。fitlog 连点 ±（60 kg 要按 4 下 +5）反而更贵。
- **热身**：fitlog 和健身房训练都没有热身组类型，按普通组记，所以便宜，但这是缺功能，不是做得好。训记、Hevy、Lyfta 标热身要多点一次。

- 每组都是 1 下。fitlog 记 20 组正好 20.0 分（48 dp 的组号就是标准组）；2026-10-26 前组号 36 dp 时是 21.4 分，比 Lyfta、训记、健身房训练多 1.5–2 分。
- fitlog 开场 2 秒：首页顶上一行「上次 · 再练一次」点一下，馆沿用上一场。2026-10-26 前要 7 秒：长按菜单 →「复制为今天的训练」→ 选馆，弹出 2 次。收尾是同一键点两下、不弹确认框；Hevy 和 Alpha 收尾还要过庆祝页或评分弹窗，更贵。
- 训记、Lyfta 的动作卡是折叠的，每换一个动作要先点开（「展开动作」一列）。
- 健身房训练、Gym WP 的 T3 便宜，前提是 T1 结束时选了「把改动写回模板」。这也是代价：放弃的训练、误删的组同样会写回模板（Gym WP 实测把卧推改成了 1 组）。

## 值得借鉴

| 做法 | 出处 | 为什么值得看 |
|---|---|---|
| 底部固定大主按钮，一路点下去 | 健身房训练 `LOG NEXT SET` | 记一组不用找目标、不用瞄准，正是「不用精确点击」该有的样子 |
| 记完一组自动聚焦下一个空格 | 健身房训练 | 首组省一次找格子 + 点格子 |
| 键盘上的「下一步」顺手完成这一组 | Lyfta | 改重量只要打数字，比连点 ± 便宜 |
| 按器械步进的 ± | Hevy、Alpha | 60 → 62.5 一下到位；fitlog 已经按馆档案取整，方向一致 |
| 超级组自动在两个动作间切换 | Lyfta | 超级组每组仍然 1 下，可以当 fitlog 做超级组的下限 |
| 结束时询问是否把改动写回模板 | 健身房训练 | 让下次预填准确；但要防止误操作也被写回去 |
| 强制停止后有「继续」恢复条 | 健身房训练、Hevy | 训练中被打断能接着记 |

## 常见痛点（fitlog 可以打的点）

- **加动作要打英文**：除了按部位翻列表，竞品找动作都靠搜索。中文 app（训记）也一样要打字，Lyfta 的动作名甚至全是英文。
- **键盘输入出错**：健身房训练的「Next」不全选原值，10 会变成 108；Gym WP 免费版搜索只露前 5 个结果；训记「新增一组」会连热身标记一起复制。
- **不可撤销的破坏性操作**：Lyfta 替换动作会直接丢掉已完成的组；Gym WP 删组没有确认、不能撤销，还会写回模板。
- **锁和打扰**：图表、1RM、导出、自定义动作数量都有付费锁；插页广告、评分弹窗、劝注册、庆祝分享页，都打断在记录前后。
- **臃肿**：训记把饮食、断食、经期、挑战都做进来，专门给了一页设置用来隐藏模块。

## fitlog 开销不是最低的地方（按影响排序）

1. **记一组还是要看、要瞄**：组号 48 dp 是标准组的 1.00 分，再往下只有短边 ≥ 192 dp 的大目标（闭着眼点得中、那一下不计视觉）。按 `fitlog_walk.py bottom=3` 算，底部半屏点击区能让 T3 再省 7 分；健身房训练 293×51 的底部按钮按这套规则和 48 dp 组号等价，不算「不用看」。
2. **± 到不了的数只能打字**：龙门架一档 5、要记 17.5 时只能打字（一组 5.0 分，用 ± 是 3.4）。连点 ± 本身不贵（第 2 下起 0.28 s、0 比特）；Lyfta 改重量便宜是因为键盘「下一步」顺手完成了组，这和 fitlog「点组号才算做完」冲突。
3. **首组仍然要用系统键盘**：和竞品的自带键盘差不多贵（自带键盘只省 0.3 s 的等待，总分 −0.2），「不强制键盘」目前只在加动作和后续组上成立。
4. **缺的记录功能**：热身组类型、RPE/RIR、替换动作，竞品普遍有。完整清单见下一节。

2026-10-26 已改掉：组号 36 → 48、开练不再弹选馆、结束确认框改成同键再点一次、首页一键「再练一次」、换动作自动滚；T1 67.2 → 64.1，T3 26.3 → 22.1（逐项见 [`effort-fitlog.md`](effort-fitlog.md)）。

### 二、刻意不做的（确认是有意的，不是漏了）

**`positioning.md` 已经写明的**：AI 教练与 AI 计划、社交动态 / 排行 / 挑战 / 分享卡、动作视频库与图解、饮食记录（含断食、经期）、付费锁和广告。竞品的臃肿和打扰几乎都出在这些地方，实测也印证了，比如训记专门留了一页设置用来隐藏模块，Gym WP 有 4 次插页广告。

**还没写进定位、需要你定的**：

- **休息计时**：6 款都有，是唯一一个所有竞品都有、fitlog 却没有的记录功能。`design-ink-and-paper.md` §12.10 写的是「做过，不好用，已删」，所以这是有意为之。但它在竞品里太普遍，建议把理由补进定位，免得以后被当成漏项再讨论一次。
- **进度照片、肌群人体图**：4–5 款有，定位里没提。照片和「最纯粹的记录」关系不大；人体图属于统计展示，可以和第 7 条一起考虑。
- **通知 / 小组件 / 手表 / 健康平台**：4 款有，定位里没提。和「不联网、不注册」不冲突，但会扩大维护面。
- **云同步与账号**：定位是「不注册」，自动备份替代了云同步。个人版连自己 NAS 的同步不对外。
- **上手问卷**：竞品普遍问身体数据和目标，fitlog 直接选馆开练（原则 4），是有意的。

## 口径与局限

- **fitlog 的分数是按代码和演示版推算的走法**（见 [`effort-fitlog.md`](effort-fitlog.md)），竞品的是真机 / 模拟器上实测的操作日志。实测日志里，每到一个新画面就要多想一下（加一个 M），可能让竞品的 T1 略偏高；但加动作那 20–30 分的差距来自打字搜索，不受这点影响。
- **重算**：操作日志、预处理和计分脚本在 [`scripts/effort/`](../../scripts/effort/README.md)。
- **自带数字键盘按键是按坐标认出来的**：探索时没有给键盘按键加标注，事后按各 app 键盘截图里的键位认，认出后按「键盘一键」计分，不按普通点按计分。Lyfta 键盘上的「下一步」兼做完成键，所以它的瞄准次数显得特别少。
- **弹窗只计入了探索时写明的**：没写明的休息计时弹层、广告不加分，竞品的分数可能略偏低。
- **Hevy、Gym WP、Alpha、健身房训练有一部分在模拟器上测**，英文系统；Lyfta、训记、Hevy 第一轮在真机上测。Lyfta 是试用期账号，被锁的范围看不全。
- 训记、Lyfta、Hevy 是用户登录、走完引导后才接手的，这三款的上手流程没有实测。
